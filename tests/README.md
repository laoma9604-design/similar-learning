## 现在覆盖什么

`tests/test_metrics.py` —— 独立结构评价器 `a_data/metrics.py` 的回归测试，20 个用例：

| 分组 | 守什么 | 任务书依据 |
|---|---|---|
| 已知答案 | 三节点 11 项、二节点 9 项、正确映射 SF=1、角色交换 SF=9/11 且 SIPR=0 | L132 / L1036 / L1113 |
| 分母规则 | 缺映射 / 缺超边 / 全空 / 角色错，清单项数都不缩水 | L1034「未匹配项记失败」 |
| 双射 | 重复占用、遗漏、超边重复占用都必须判失败 | L341「不能遗漏或重复占用」 |
| 错误归类 | type / endpoint / role 三类不串味 | L1327 |
| 聚合 | SF/SIPR 是任务平均，无候选计入分母 | L1034 |
| 真实数据 | MRED 300 组 / 300 正任务，gold 映射全满分且项数与结构吻合 | 数据自检 |

## 这套测试抓得住真 bug 吗

抓得住，已用变异测试验证过（2026-10-29）：

| 故意引入的错误 | 结果 |
|---|---|
| 把"重复占用判失败"改回宽松处理 | 2 个用例失败 |
| 让清单分母随候选质量收缩（最初那个 bug） | 5 个用例失败 |

两次变异都立刻报红，改回后 20 个用例恢复全绿。所以这套测试不是摆设。

## 什么时候必须跑

- 改 `a_data/metrics.py` 任何一行 —— 必跑
- 改 `cases/` 下任何数据（尤其 sealed/reference.json）—— 必跑，最后一条用例会抓出数据与口径不一致
- 交给 C 复核独立评价器之前 —— 必跑，把输出截给 C
