# MRED 域对规格表（生成器输入清单）

25 个真实「源 → 目标」域对，三类关系。生成器按此表批量产 cases/。本表是数据构造的权威底稿，字段与 T01-schema 对齐，数值待 C 复核。

## 一、关系类型统一约定（三类通用，不逐条重复）

### 1. multiplicative_growth 乘性增长
- 方程模板：`next = current * (1 + ratio)`
- 角色：current(当前量,-) / ratio(变化比例,-) / next(下一步量,+)
- node_map 模板：current_s→current_t、ratio_s→ratio_t、next_s→next_t
- legal_domain：current∈[0,∞]、ratio∈[0,1]（增长率稳定假设）
- 干预范围：±0.2（current、ratio 同）
- input_scales 取各自 baseline 本身；output_scale 取 baseline_output

### 2. linear_drive_resistance 线性驱动-阻力
- 方程模板：`response = driver / resistance`
- 角色：driver(驱动量,-) / resistance(阻力量,-) / response(响应量,+)
- node_map 模板：driver_s→driver_t、resistance_s→resistance_t、response_s→response_t
- legal_domain：driver∈(0,∞)、resistance∈(0,∞)，下界落地为 1e-6（严格正，防除零）
- 干预范围：±0.2
- 尺度规则：input_scales 取各自 baseline 本身（driver 取 driver₀、resistance 取 resistance₀）；output_scale 取 baseline_output（= driver₀/resistance₀）。线性类归一化响应只依赖 u 的相对变化，天然跨域一致，无额外约束。

### 3. saturation_response 饱和响应
- 方程模板：`response = R_max * input / (K + input)`，R_max、K 为内联常量（非节点）
- 角色：input(输入量,-) / response(响应量,+)
- node_map 模板：input_s→input_t、response_s→response_t
- legal_domain：input∈(0,∞)，下界 1e-6；R_max>0、K>0 在生成脚本断言
- 干预范围：[-0.8, 1.0]（放宽，理由：饱和反例只在进入饱和区才暴露，见 关系公式初稿.md 第 2 节）
- 尺度规则：input_scales 取 baseline 本身（input 取 input₀）；output_scale 取 baseline_output（= R_max·input₀/(K+input₀)）。
- 关键约束（饱和类独有）：两域 input₀ 必须处于相对 K 的同一位置，**约定取 input₀ = K（半饱和点）**。原因：归一化响应 r = u/(2+u)（该式仅在 input₀=K 时成立）；若 input₀ ≠ K，响应含 a=K/input₀ 项，两域 a 不同则正例响应不一致。实测反证：input₀=2K 时偏差达 0.133。本表所有饱和域对的 baseline 均已取 input₀ = K。
  - **旧版遗留矛盾已废止**：此前同期出现的「input₀ ∈ {0.5K, 1K, 2K}」与 input₀=K 互斥，只有 1K 能同时成立，该写法作废。
  - 参数变体只能改 R_max 与 K（input₀ 跟随 = K）；改 R_max 不影响归一化响应，改 K 才产生新的工作点。

## 三、线性驱动-阻力（8 个）

> 源域统一用「电路（欧姆定律）」做原型（它是驱动-阻力关系最经典、最易懂的锚点，类比饱和响应用酶催化做源同理），目标域换成各「流量=驱动力/阻力」现象。最后一个用热传导→扩散（两个输运现象互比）。

### 10. 电路 → 水流（已落 group_dev_0004）
领域依据：源=欧姆定律 I=V/R；目标=泊肃叶/达西定律 Q=ΔP/R。跨域：电→流体。
- 源「电路」：driver=电压 V(V)、resistance=电阻 R(Ω)、response=电流 I(A)
  - `V / R`；V=10, R=2 → I=5
- 目标「水流」：driver=压差 ΔP(kPa)、resistance=流阻 Rf(kPa·s/L)、response=流量 Q(L/s)
  - `dP / Rf`；ΔP=8, Rf=4 → Q=2

### 11. 电路 → 热传导（欧姆↔傅里叶）
领域依据：源=欧姆定律；目标=傅里叶热传导 q=ΔT/Rth。跨域：电→热。
- 源「电路」：driver=V、resistance=R、response=I；`V / R`；V=12, R=3 → I=4
- 目标「热传导」：driver=温差 ΔT(K)、resistance=热阻 Rth(K/W)、response=热流 q(W)
  - `dT / Rth`；ΔT=24, Rth=6 → q=4

### 12. 电路 → 扩散（欧姆↔菲克）
领域依据：源=欧姆定律；目标=菲克扩散 J=ΔC/Rd。跨域：电→传质。
- 源「电路」：`V / R`；V=9, R=3 → I=3
- 目标「扩散」：driver=浓度差 ΔC(mol/m³)、resistance=扩散阻力 Rd、response=扩散通量 J(mol/(m²·s))
  - `dC / Rd`；ΔC=6, Rd=2 → J=3

### 13. 电路 → 力学阻尼（欧姆↔阻尼）
领域依据：源=欧姆定律；目标=线性阻尼 v=F/c。跨域：电→力学。
- 源「电路」：`V / R`；V=15, R=5 → I=3
- 目标「力学阻尼」：driver=力 F(N)、resistance=阻尼系数 c(N·s/m)、response=速度 v(m/s)
  - `F / c`；F=12, c=4 → v=3

### 14. 电路 → 磁路（欧姆↔磁阻）
领域依据：源=欧姆定律；目标=磁路欧姆定律 Φ=Fm/Rm。跨域：电→磁。
- 源「电路」：`V / R`；V=8, R=2 → I=4
- 目标「磁路」：driver=磁动势 Fm(A·匝)、resistance=磁阻 Rm、response=磁通 Φ(Wb)
  - `Fm / Rm`；Fm=16, Rm=4 → Φ=4

### 15. 电路 → 血流动力学
领域依据：源=欧姆定律；目标=血流阻力 Q=ΔP/Rv。跨域：电→生理。
- 源「电路」：`V / R`；V=10, R=2 → I=5
- 目标「血流」：driver=血压差 ΔP(mmHg)、resistance=血管阻力 Rv、response=血流量 Q(L/min)
  - `dP / Rv`；ΔP=100, Rv=20 → Q=5

### 16. 电路 → 渗流（达西定律）
领域依据：源=欧姆定律；目标=达西渗流。跨域：电→多孔介质流体。
- 源「电路」：`V / R`；V=6, R=3 → I=2
- 目标「渗流」：driver=压力梯度 ΔP(kPa)、resistance=渗透阻力 R、response=渗流量 Q
  - `dP / R`；ΔP=8, R=4 → Q=2

### 17. 热传导 → 扩散（傅里叶↔菲克，两个输运现象）
领域依据：源=傅里叶热传导；目标=菲克扩散。跨域：热→传质（同为梯度驱动输运）。

## 四、饱和响应（8 个）

> 源域以「酶催化（米氏方程）」为锚点（最经典饱和原型），目标换各饱和现象。标「理想 n=1」与「二级正例」的需在数据说明里注明简化假设。

### 18. 酶催化反应 → Langmuir 表面吸附（已落 group_dev_0005）
领域依据：源=Michaelis-Menten 酶动力学；目标=Langmuir 吸附等温线。跨域：生化→物理化学（标杆）。
- 源「酶催化」：input=底物浓度 [S](mM)、response=反应速率 v(μM/min)；R_max=10, K=1
  - `10.0 * S / (1.0 + S)`；[S]=1 → v=5
- 目标「吸附」：input=平衡浓度 C(mg/L)、response=吸附量 q(mg/g)；R_max=20, K=2
  - `20.0 * C / (2.0 + C)`；C=2 → q=10

### 19. 酶催化反应 → 微生物 Monod 生长
领域依据：源=米氏方程；目标=Monod 生长方程 μ=μ_max·S/(Ks+S)。跨域：生化→微生物。
- 源「酶催化」：`10.0 * S / (1.0 + S)`；R_max=10, K=1；[S]=1 → v=5
- 目标「Monod 生长」：input=底物浓度 S(g/L)、response=比生长速率 μ(h⁻¹)；μ_max=2, Ks=0.5
  - `2.0 * S / (0.5 + S)`；S=0.5 → μ=1

### 20. 酶催化反应 → 受体-配体结合
领域依据：源=米氏方程；目标=受体-配体结合等温线 B=B_max·[L]/(Kd+[L])。跨域：生化→细胞生物。
- 源「酶催化」：`10.0 * S / (1.0 + S)`；R_max=10, K=1；[S]=1 → v=5
- 目标「受体结合」：input=配体浓度 [L](nM)、response=结合量 B(nM)；B_max=100, Kd=10
  - `100.0 * L / (10.0 + L)`；[L]=10 → B=50

### 21. 酶催化反应 → 光合作用光响应
领域依据：源=米氏方程；目标=光合光响应曲线 P=P_max·I/(K+I)。跨域：生化→植物生理。
- 源「酶催化」：`10.0 * S / (1.0 + S)`；R_max=10, K=1；[S]=1 → v=5
- 目标「光合」：input=光强 I(μmol/m²/s)、response=光合速率 P(μmol CO₂/m²/s)；P_max=20, K=200
  - `20.0 * I / (200.0 + I)`；I=200 → P=10

### 22. 载体介导营养吸收 → 肾脏葡萄糖重吸收
领域依据：源=载体介导饱和转运；目标=肾小管葡萄糖重吸收 T=T_max·[G]/(Km+[G])。跨域：同机制不同生理场景。

简化假设：离子通道配体门控实际常具协同（Hill n>1），此处取理想 n=1（非协同）模型，才套得上饱和响应模板。

## 五之二、三类干扰的构造规则（tab:mred 四行逐条落地）

### 结构与响应均有效（真实源域）

构造操作（L999）：**重命名 + 打乱节点顺序 + 按有共同含义的单位或尺度变换参数**。

- 重命名：节点 ID 从统一 ID 池随机分派，与干扰源共用同一池，杜绝命名泄露
- 打乱节点顺序：`nodes` 列表顺序按 `stable_hash(group_id, "src_order")` 随机排列
- 尺度变换：乘性只动 current；线性动 driver 与 resistance；饱和动 R_max/K（input₀ 跟随 = K）
- 独立核验依据：网格扫描两域归一化响应，最大偏差 ≤ 1e-9（实测量级 1e-16）

### 结构错误

构造操作：交换角色、改变输入输出端、改变某条关系的连接。
本库实现：让源域输出对输入不成立正确的角色对应（输出随输入反向变化），类型/角色标注照抄同关系模板。
独立核验依据：该源域在干预区间内的最大响应误差远超容差（实测 0.16～1.00）。

### 结构相同、响应错误

构造操作：保持类型、角色、端点不变，改变函数形式。
本库实现：乘性改二次项形式、线性改幂律、饱和改 Hill n=2。
独立核验依据：保存合法见证干预、两域输出及误差；实测最大误差 0.0576（乘性/线性）、0.0902（饱和）。

### 局部扰动容易通过（对应任务书 L170 反例三）

构造操作：在预设输入域的某个子区间产生较大响应差异。

**公式（任务书 L170 原式）**：

```
b(u) = 0.3 × [ exp(−((u−0.13)/0.03)²) − exp(−(0.13/0.03)²) ]
源响应 = 目标响应 + b(u)          # 加在【归一化响应】空间，不是输出值空间
```

**唯一性核验数值（已实跑复现任务书原值）**：

| 检查点 | 单输出误差 b(u)² |
|---|---|
| 五点 {−0.2, −0.1, 0, 0.1, 0.2} 最大 | 0.012180（< 0.05，会误判为有效） |
| u = 0.13 见证点 | 0.090000（> 0.05，超容差） |
| 超容差区间 | u ∈ [0.114, 0.146]，宽 0.032，占全区间 8.2% |

独立核验依据：用解析界或独立高覆盖检查定位见证区间，用于比较搜索能力。**见证区间的数值由 C 独立核验后签字，A 侧自查不算数。**

## 六、生成落地注意（JSON 高频出错点）

1. baseline 顺序：baseline / input_scales 是「按 controllable_inputs 顺序」的列表。线性顺序 [driver, resistance]，乘性 [current, ratio]，饱和 [input]。生成器必须按此顺序对齐，不得错位。
2. 常量/节点边界：饱和响应的 R_max、K 是内联常量，写死在 function 字符串里，不进 controllable_inputs、不进 legal_domain、不进 baseline。只有 input 是可干预节点。
3. 简化假设溯源：第 23「理想 n=1」、第 24「单体血红蛋白/二级正例」的简化假设，除本表外，须在数据说明文档里逐条溯源（哪个域对、假设什么、为何简化），否则 C 复核时会与真实生理事实冲突。
