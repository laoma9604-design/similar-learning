本文件是任务书 L973–L1024 要求的数据说明文档，覆盖 T02 交付物清单。MRED = Mechanistic Response Evaluation Dataset，本项目自建，与 SCAR/SCAN 并列的三个独立数据源之一，不从二者派生。

**v2 修订（2026-11-01）**：v1 经评审发现四条数据缺陷，全部实测确认后重写生成器并重建全库。四条与修法见第十二节，本节以下所有数字均为重建后实测值。

生成脚本：`a_data/gen_mred_formal.py`（对象构造 `a_data/mred_objects.py`，干扰源 `a_data/mred_interference.py`，域对规格 `a_data/mred_domains.py`）。独立验收脚本：`a_data/verify_mred.py`（不 import 生成器，按任务书原文重新实现判据）。

## 二、真实领域对象与合成变体分开统计（任务书 L993）

- **真实领域对象**：25 个「源→目标」域对 × 2（源 + 目标）= **50 个基础对象**，各自注明领域依据（欧姆定律 / 傅里叶定律 / 米氏方程 / 复利公式等），逐条见 `data/MRED域对规格.md`。
- **参数变体**：同一真实域对更换合法工作点，**不算新的真实对象**。300 组由 25 个域对 × 平均 12 个参数变体展开。
- **受控合成对象**：全部 3000 个干扰源，标 `controlled_synthetic: true`，存于各组封存区 `counterexamples/`，**不进方法输入**。

**如实声明**：300 组的信息来源是 25 个真实现象 × 参数刻度，不是 300 个独立现象。规模为任务书 L991 的最小候选档（300）。

### 参数变体必须真的不同（v2 修正）

v1 的乘性类只动 `current`，`ratio` 被强制对齐到目标域，导致**同一域对不同组之间出现 4636 对完全相同的对象签名**——变体形同虚设，且这些重复对象跨划分，构成 L1020 禁止的泄漏。

v2 引入 `MULT_RATIO_TIERS` 八档（0.02/0.05/0.10/0.15/0.20/0.30/0.40/0.50）：

- **组内**：源域与目标域的 ratio 取同一档 → 正例归一化响应严格等价（约束 1）；
- **组间**：按该域对在类内的序号轮换档位 → 变体真的有差异，跨组签名不再重复（独立验收 C3 项实测 0 组重复）。

## 三、三类关系五要素（任务书 L993）

### 1. multiplicative_growth 乘性增长

- **方程**：`next = current × (1 + ratio)`，两个可控输入
- **变量含义**：current = 当前量；ratio = 变化比例；next = 下一期量
- **参数范围**：current ∈ [0, +∞)；ratio ∈ [0, 1]
- **求值顺序**：单关系单步，输入先取 `baseline + input_scales × u`，再代入函数
- **适用条件**：两域 ratio 必须相同（约束 1）

### 2. linear_drive_resistance 线性驱动-阻力

- **方程**：`response = driver / resistance`，两个可控输入
- **变量含义**：driver = 驱动量；resistance = 阻力量；response = 响应量
- **参数范围**：driver、resistance ∈ (0, +∞)，下界 1e-6（防除零）
- **求值顺序**：同上
- **适用条件**：线性输运、阻力在工作点邻域内视为常数

### 3. saturation_response 饱和响应

- **方程**：`response = R_max × input / (K + input)`，R_max、K 为内联常量（非节点），单个可控输入
- **变量含义**：input = 输入量；response = 响应量；R_max = 饱和上限；K = 半饱和常数
- **参数范围**：input ∈ (0, +∞)；R_max > 0、K > 0 由生成脚本断言
- **适用条件**：单底物、无协同（Hill n=1）；input₀ = K（约束 2）

## 四、基准与尺度（任务书 L1012–L1017）

- **baseline**：取该现象的真实可见量级，不是训练样本。
- **input_scales**：三类统一取 **baseline 本身**。
- **output_scale**：三类统一取 **baseline_output**。
- **归一化响应**：`r = (y(u) − y₀) / output_scale`，输入 `= baseline + input_scales × u`。
- **尺度不随方法调参变化**：本组容差属数据版本，不与方法阈值 γ/ζ 联动（L1010）。
- **尺度敏感性**：线性类 `r = (1+u_d)/(1+u_r) − 1` 与 baseline 无关；饱和类 `r = u/(2+u)` 与 R_max、K 无关。

---

## 五、数学约束（生成器强制断言，违反即中止）

**约束 1：乘性类两域 ratio 必须相同。**
归一化响应含 r₀ 项，两域 r₀ 不同则正例响应不等价（实测 r₀ = 0.2 vs 0.03 时偏差 0.033）。每一域对的两域统一取同一档位（组内一致），档位在域对之间轮换（组间有别）——这一条同时满足正例严格等价和参数变体有效。

**约束 2：饱和类两域 input₀ 必须 = K（半饱和点）。**
反证：input₀ = 2K 时偏差立刻达到 0.133。

**约束 3：output_scale 必须取对象自身的 baseline_output。**
取错尺度会把响应误差压平。

## 六、参考容差与见证点（任务书 L1010）

- **参考容差**（数据版本，先于方法调参固定）：`min_ctc = 0.95`，`max_error = 0.05`，逐任务记在 `sealed/reference.json`。
- **判定口径**：所有响应误差在**统一的 0.05 步长网格**上计算（二维为 31×31 = 961 点，饱和类一维 37 点）。生成器与独立验收脚本用同一网格，第三方复算不会出现「疏密不同结论不同」。
- **正例等价**：300 组 × 每输入维 5 点的全笛卡尔积，两域归一化响应最大偏差 ≤ 1e-9。
- **负例见证**：每个被排除的候选源域在 `sealed/reference.json` 的 `exclusions[i]` 里给出顶层 `witness`（`u_target`、`u_source`、`r_target`、`r_source`、误差、`node_map`），只读这一个文件就能复算，不必翻 `counterexamples/`。

### 三类干扰的实测误差（全库 3000 个干扰源，标准 0.05 步长网格）

| 类型 | 个数 | 最大误差（min~max，均值） | 说明 |
|---|---|---|---|
| 结构错误 | 900 | 0.0000（全部） | 响应与目标完全一致，**靠结构项排除**（某个被标注为输入的节点实际不影响输出）。这类源故意做成「结构错、响应一致」，用来单独检验 A03「去除离散结构校验」会放出多少候选 |
| 响应错误 | 1200 | 0.0581 ~ 1.0000，均值 0.3080 | 结构全对，只有函数形式不同。按关系类型分：乘性 0.0581~0.3172（均值 0.1669）、线性 0.1806~1.0（0.4597）、饱和 0.0811~1.0（0.3443） |
| 局部扰动 | 900 | 0.0784 ~ 0.1156，均值 0.0947 | 稀疏五点最大 0.0131 < 0.05（容易通过），标准网格 0.078~0.116 > 0.05（稠密检查必然失败） |

**同类干扰源必须彼此不同。** 每个组里有 3 个结构错误、4 个响应错误、3 个局部扰动源，同类之间用不同的构造水平/函数族/鼓包位置，保证 10 个候选是 10 个不同对象。生成器有断言守这一条（早期版本同类函数完全一样、只有 ID 不同，等于把 3 个候选虚报成 10 个）。

响应错误用的 4 个函数族（每类关系各 4 个，全部实测超过 0.05 容差）：

- 乘性：`current^3`（0.281）、`current^2.5`（0.144）、二次+交叉项（0.174）、`current^2`（0.0581）
- 线性：`driver^2`（0.436）、`driver^2.5`（0.223）、二次+交叉项（0.181）、`driver^4`（1.000）
- 饱和：Hill n=2（0.090）、Hill n=3（0.206）、有理式（1.000）、Hill n=0.5（0.081）

**实测踩过的两个坑**（写进代码注释防止回退）：

1. ratio 通常只有 0.02~0.5，在 ratio 侧做任何改动都会被归一化响应抵消（实测 `current*(1+2*ratio)` 配合基准点归一化后误差 < 1e-5）。只有对 current/driver 做非线性才产生稳定可见的偏差。
2. 鼓包中心必须落在 0.05 网格点上、或与最近网格点距离小于宽度，否则标准网格采不到峰值（曾用 center=0.18/width=0.018，离最近点 0.02 > 宽度，实测误差只有 0.0076，低于容差，导致负任务里混进有效映射）。

### 局部扰动的构造（v2 修正）

v1 把鼓包直接加在主输入维的 u 上，v2 改为加在**全部输入维无量纲扰动的均方根** `u_norm = sqrt(mean_j((x_j−b_j)/b_j)²)` 上——否则第二维「被标注为输入却完全不影响输出」，会被端点探测判成结构错误。

```
b(u_norm) = 0.30 × [ exp(−((u_norm−0.20)/0.020)²) − exp(−(0.20/0.020)²) ]
```

参数取值全部经数值试算选定：

- 峰值 = 0.30 → 单输出误差 **0.09** > 容差 0.05；
- L175 的稀疏五点上（每维 −0.2/−0.1/0/0.1/0.2，其余维置 0，故 u_norm ∈ {0, 0.0707, 0.1414}），鼓包取值接近 0 → 误差 **0.013** < 0.05，**稀疏点容易通过**；
- 饱和类（单输入，区间 [−0.8, 1.0]）的稀疏五点取该区间的 0/25/50/75/100% 分位（−0.8/−0.35/0.1/0.55/1.0），全部落在鼓包外；
- 标准 0.05 步长网格上可采到 u_norm≈0.20 → 误差 0.09，**稠密检查必然失败**。

即：局部反例的定义（L1002「在预设输入域的某个子区间产生较大响应差异」）在**固定的稀疏点和固定的标准网格**上就能稳定成立，不依赖加密网格的运气。

**表述约束**：有限测试通过表述为「通过独立验证」，不宣称全域严格等价。

## 七、负任务全库核验（任务书 L1008）

这是 v1 最弱的一环：`full_library_verified: true` 是写死的常量，`reference_all.jsonl` 里 0 条带见证，枚举空间根本没做。v2 改为真枚举：

1. 对候选库里**每个**源域，枚举全部类型兼容的节点双射（本库节点全为 positive_scalar，3 节点 → 6 个，饱和类 2 节点 → 2 个）与超边双射；
2. 逐个映射按式(eq:structure) 检查：节点双射、超边双射、每节点类型、超边类型、输入集合、输出集合、角色，**外加 L1000 的「端点标注与实际依赖一致」**（把被标注为输入的节点实际值改动 10%，输出必须变化——纯标注比对看不出「改变输入输出端」这种结构错误）；
3. 结构通过者再做响应检验，超过参考容差即排除；
4. `allowed_mappings_total` 记录实际枚举数（每组 60），`exclusions[i].detail` 记录每个映射被哪一项拒绝；
5. `full_library_verified` 由上述结果**算出**，不是常量。成立条件：
   - 无任何源域存在有效映射；
   - 每个源域的候选映射都被枚举过；
   - **结构错误类**的全部映射在结构项上失败（比响应超容差更强的证据，不要求响应误差——这类源故意构造成「结构错、响应可能一致」，用于单独检验 A03）；
   - **响应错误/局部扰动类**必须有超过参考容差的见证响应误差。

## 八、数据划分（任务书 L1020）

- 比例目标 **70% / 15% / 15%**，种子 **20261007**；实际 **train 210 / val 42 / test 48**（每域对 12 组为不可分单位，边界只能落在域对之间，与目标差 3 组）
- **为什么不拆到严格 45/45**：拆开某个域对就能凑够 45，但同一域对的变体就会跨划分，直接违反 L1020「同一对象的改写、参数变体、派生映射和正负任务留在同一组」，也违反 L1020 后半句「跨任务共享的相同对象与派生对象须合并分组，或从跨划分复用中移除」。泄漏风险大于 3 组配额偏差，因此选择保持域对完整（2026-11-01 与项目负责人确认）。
- **划分单位 = 域对**：同一域对的全部参数变体、正负任务、派生对象进同一划分。pair 是不可分单位（每对 12 组），在 pair 边界上穷举分割点，取与 70/15/15 偏差最小的切法。
- **跨任务共享的相同对象与派生对象**：v2 起不再存在——参数变体签名组间不重复（第二节），独立验收 C3 项检查「同域对跨组完全相同的对象签名」必须为 0。
- 关系家族允许跨划分出现（L1022），检验家族内泛化；基础实例及其派生不重复。

**v1 缺陷**：按组随机划分，导致 21/25 个域对跨 train/val/test，同域对的对象在训练集和测试集同时出现。

## 十、答案隔离（任务书 L1006）

方法输入（`data/input/`）不含任何标签与见证答案。v1 有五条独立的泄漏路径，**每条都能 100% 判出答案**，v2 逐条封堵：

| v1 泄漏路径 | v1 实测 | v2 处置 | v2 实测 |
|---|---|---|---|
| 有效源固定在 `source_ids[0]` | 300/300 | 候选顺序按 `hash(组ID,"source_order")` 打乱 | 命中率 ≈ 随机基线 1/10 |
| 文件名 `positive.json` / `negative.json` | 300/300 | 任务文件名改为 `task_<组>_t01.json` / `_t02.json` | 0 |
| 有效源 label 是真实领域名（「细菌二分裂」），干扰源是「候选源域」 | 300/300 | 所有候选源 label 统一「候选源域」，真实名只进 `relation/analogy.json`（封存） | 0 |
| 节点 ID 前缀不同（有效源 `b*`，干扰源 `n1/n2`） | 300/300 | 目标域、有效源、干扰源全部从同一 `v1..v9` 池分派，组内一致、跨组随机 | 0 |
| 只有有效源节点数 = 目标节点数（3=3） | 276/300 可判 | 所有候选源与目标域节点数相同 | 0 |
| 节点 label 含领域词（当前本金/本期利率） | 全库 | 中性化为「量 A/量 B/量 C」 | 0 |

| 内容 | 位置 | 可见性 |
|---|---|---|
| 对象 nodes / edges / function / baseline / scales | `data/input/objects/` | 公开（方法输入） |
| 任务（目标 + 10 候选源域 + 干预范围） | `data/input/tasks/` | 公开（方法输入） |
| 真实领域名与节点语义标签 | `relation/analogy.json` | 封存 |
| 正确答案与标签 | `manifest.sealed.json` | 封存 |
| 解析映射、节点/边映射、角色、领域依据 | `relation/` | 封存（复核材料） |
| 标签、枚举证据、见证点 | `sealed/reference.json` | 封存（仅评价器） |
| 受控合成标注、见证点 | `counterexamples/` | 封存 |

**残留可辨识性（如实声明）**：`function` 字段是方法求值的必要输入，无法隐藏。三类干扰的函数形式天然不同（局部扰动含 `exp` 项、结构错误把某个输入写成常数）。这属于「函数形式的固有差异」，不构成显式标签，但可能被字符串启发式利用。本库按任务书 L1006 的字面约束（节点数 / 文件名 / 描述）执行，函数形式差异视为公开输入的一部分，在 E08 案例分析中说明。
