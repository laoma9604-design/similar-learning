# MRED 正式库数据说明

本文件是任务书 L973–L1024 要求的数据说明文档，覆盖 T02 交付物清单。MRED = Mechanistic Response Evaluation Dataset，本项目自建，与 SCAR/SCAN 并列的三个独立数据源之一，不从二者派生。

生成脚本：`a_data/gen_mred_formal.py`（对象构造 `a_data/mred_objects.py`，干扰源 `a_data/mred_interference.py`，域对规格 `a_data/mred_domains.py`）。全部数值经 `a_data/runtime.py` 实跑验算，验算不过即中止，不落盘。

## 二、真实领域对象与合成变体分开统计（任务书 L993）

- **真实领域对象**：25 个「源→目标」域对 × 2（源 + 目标）= **50 个基础对象**，各自注明领域依据（欧姆定律 / 傅里叶定律 / 米氏方程 / 复利公式等），逐条见 `data/MRED域对规格.md`。
- **参数变体**：同一真实域对更换合法工作点（baseline 数值 / R_max / K），**不算新的真实对象**，单列为「同一现象的不同工作点」。300 组即由 25 个域对 × 平均 12 个参数变体展开而成。
- **受控合成对象**（人为改函数得到）：全部 3000 个干扰源，标 `controlled_synthetic: true`，存放在各组封存区 `counterexamples/`，**不进方法输入**。
- 上述三类的划分是：真实对象 50 → 参数变体展开为 300 组 → 每组配 10 个受控合成干扰源。

**如实声明**：300 组的信息来源是 25 个真实现象 × 参数刻度，不是 300 个独立现象。规模选择为任务书 L991 的最小候选档（300），后续如需扩到 600/1200，按 L1236 采用嵌套训练子集，不重新生成。

## 三、三类关系五要素（任务书 L993）

### 1. multiplicative_growth 乘性增长

- **方程**：`next = current × (1 + ratio)`
- **变量含义**：current = 当前量（当前本金 / 当前细菌数 / …）；ratio = 变化比例（本期利率 / 每代增长率）；next = 下一期量
- **参数范围**：current ∈ [0, +∞)；ratio ∈ [0, 1]（增长率稳定假设）
- **求值顺序**：单关系单步求值，无环，输入先取 `baseline + input_scales × u`，再代入函数
- **适用条件**：变化比例在干预区间内保持恒定；两域 ratio 必须相同（见第五节约束 1）

### 2. linear_drive_resistance 线性驱动-阻力

- **方程**：`response = driver / resistance`
- **变量含义**：driver = 驱动量（电压 / 温差 / 压差）；resistance = 阻力量（电阻 / 热阻 / 流阻）；response = 响应量（电流 / 热流 / 流量）
- **参数范围**：driver ∈ (0, +∞)，resistance ∈ (0, +∞)，下界落地为 1e-6（严格正，防除零）
- **求值顺序**：同乘性，单关系单步
- **适用条件**：线性输运、阻力在工作点邻域内视为常数

### 3. saturation_response 饱和响应

- **方程**：`response = R_max × input / (K + input)`，R_max、K 为内联常量（非节点，不进 controllable_inputs / baseline / legal_domain）
- **变量含义**：input = 输入量（底物浓度 / 光强 / 配体浓度）；response = 响应量（反应速率 / 光合速率 / 结合量）；R_max = 饱和上限；K = 半饱和常数
- **参数范围**：input ∈ (0, +∞)，下界 1e-6；R_max > 0、K > 0 由生成脚本断言
- **求值顺序**：同乘性，单关系单步
- **适用条件**：单底物、无协同（Hill n=1）；input₀ = K，见第五节约束 2

## 四、基准与尺度确定依据（任务书 L1012–L1017）

- **baseline（工作点）**：取该现象的真实可见量级（如银行本金 5000 元、体温差 24 K、酶底物 1 mM），不是训练样本。函数显式写死，一个工作点即足以确定尺度。
- **input_scales**：三类统一取 **baseline 本身**。
- **output_scale**：三类统一取 **baseline_output**。
- **归一化响应定义**：`r = (y(u) − y₀) / output_scale`，`u` 为无量纲干预量，`输入 = baseline + input_scales × u`。
- **尺度不随方法调参变化**：本组容差属数据版本，不与方法阈值 γ/ζ 联动（L1010）。
- **尺度敏感性**：线性类归一化响应 `r = (1+u_d)/(1+u_r) − 1` 与 baseline 无关（已实跑验证：baseline 相差 30 倍时偏差 2.2e-16）；饱和类 `r = u/(2+u)` 与 R_max、K 无关（量级差 375 倍时偏差 1.1e-16）。

---

## 五、数学约束（生成器强制断言，违反即中止）

**约束 1：乘性类两域 ratio 必须相同。**
归一化响应 `r = u_c + r₀·u_r/(1+r₀) + r₀·u_c·u_r/(1+r₀)` 含 r₀ 项，两域 r₀ 不同则正例响应不等价（实测 r₀ = 0.2 vs 0.03 时偏差 0.033，远超 1e-9）。因此每一域对的两个域统一取**目标域的 ratio**：目标是被解释对象，其参数不动；源域作为比喻，其增长率对齐到目标同一量级是类比成立的前提（对应 L999「按有共同含义的单位或尺度变换参数」）。对齐后源域增长率落在 2%–10%，均为真实可见值。

**推论**：乘性类仅 current 维度可跨域干预，ratio 作为固定参数（ratio 维度的响应亦依赖 r₀，无法跨域比较）。故乘性对象 `controllable_inputs` 仍含两项，但干扰源与响应比较只在 current 维度上进行。

**约束 2：饱和类两域 input₀ 必须 = K（半饱和点）。**
`r = u/(2+u)` 的推导前提是 input₀ = K。反证：input₀ = 2K 时偏差立刻达到 0.133。本库所有饱和域对的 baseline 均已取 input₀ = K。

**约束 3：output_scale 必须取对象自身的 baseline_output。**
`runtime.normalized_response` 用对象自身的 baseline_output / output_scale 归一化，取错尺度会把响应误差压平（开发中曾因误用目标域尺度使误差虚低至 0.04）。

## 六、参考容差与见证点（任务书 L1010）

- **参考容差**（数据版本，先于方法调参固定）：`min_ctc = 0.95`，`max_error = 0.05`。逐任务记在 `sealed/reference.json` 的 `reference_tolerance`。
- **正例等价依据**：解析正例保留响应等价依据，5400（300 组 × 2 个输入维度网格）个扫描点上两域归一化响应最大偏差均 ≤ 1e-9，实测量级为 1e-16。
- **负例见证点**：每个干扰源都提供超过参考容差的见证点（`counterexamples/<obj>/witness.json`）。三类干扰的典型量级：
  - 结构错误：最大误差 0.16（乘性/线性）～1.00（饱和）
  - 响应错误：最大误差 0.0576（乘性/线性）～0.0902（饱和）
  - 局部扰动：稀疏五点最大 0.0122（**低于** 0.05）→ 全扫见证点 0.0900（**高于** 0.05），见证点位于 u ≈ 0.13，超容差区间仅 u ∈ [0.114, 0.146]（占全区间 8.2%）
- **表述约束**：有限测试通过的映射表述为「通过独立验证」，不宣称全域严格等价。

### 局部扰动的构造（任务书 L170 原式）

```
b(u) = 0.3 × [ exp(−((u−0.13)/0.03)²) − exp(−(0.13/0.03)²) ]
```

源响应 = 目标响应 + b(u)（**加在归一化响应空间**，不是输出值空间）。减第二项使 b(0)=0。

## 十、答案隔离（任务书 L1006）

方法输入（`data/input/`）不含任何标签与见证答案：

| 内容 | 位置 | 可见性 |
|---|---|---|
| 对象 nodes / edges / function / baseline / scales | `data/input/objects/` | 公开（方法输入） |
| 任务（目标 + 10 候选源域 + 干预范围） | `data/input/tasks/` | 公开（方法输入） |
| 正确答案与标签 | `manifest.sealed.json` | 封存 |
| 解析映射、节点/边映射、角色、领域依据 | `relation/` | 封存（复核材料） |
| 标签、依据、见证点 | `sealed/reference.json` | 封存（仅评价器） |
| 受控合成标注、见证点 | `counterexamples/` | 封存 |

**防标签泄漏措施**（L1006）：
- 对象 `label`：真实对象用中性现象名（细菌二分裂 / 银行复利），干扰源统一用「候选源域」
- `object_id`：干扰源用 `obj_<group>_iNN` 流水号，不编码类别；正负任务的干扰源共用同一批 ID
- 节点数：全部对象统一 2 节点（输入 + 输出），不泄露类别
- 节点 ID：正例源域与干扰源共用同一套无意义 ID 池，不出现 `input`/`response` 与 `x1`/`y1` 的可辨识差异
- 文件名、README 描述不含「错误」「反例」「干扰」字样

**残留可辨识性（如实声明）**：`function` 字段是方法求值的必要输入，无法隐藏。三类干扰与真实源域的函数表达式复杂度天然不同（如局部扰动含 `exp` 项、结构错误形式极简）。这属于「函数形式的固有差异」，不构成显式标签，但可能被字符串启发式利用。本库按任务书 L1006 的字面约束（节点数 / 文件名 / 描述）执行，函数形式差异视为公开输入的一部分，在 E08 案例分析中予以说明。

## 十一、简化假设溯源（复核时必须知晓）

| 域对 | 简化假设 | 原因 |
|---|---|---|
| sat_06 离子通道配体门控 → 受体-配体结合 | 取理想非协同模型（Hill n=1） | 真实配体门控通道常具协同（n>1），套不上饱和响应模板 |
| sat_07 Langmuir 气体吸附 → 单体血红蛋白结合 | 取单体血红蛋白（肌红蛋白型，n=1） | 真实血红蛋白为四聚体、具协同（Hill n≈2.8），非真实 Hb 四聚体 |
| mult_05 人口增长 → 年金账户 | 假设增长率/利率在期数内稳定 | 复利公式的前提 |

## 十二、函数可求值与合法域（任务书 L1109）

- 求值器支持 `+ − × ÷ **` 与 `exp()`，全部 3300 个对象（300 目标 + 300 有效源 + 3000 干扰源）在各自主输入工作点上均可求值，`baseline_output` 与实跑一致
- 饱和类 R_max、K 为内联常量，不进 `controllable_inputs` / `baseline` / `legal_domain`
- legal_domain 用 `null` 表示无穷，runtime 按 ±∞ 处理
- 干预范围：乘性/线性 ±0.2；饱和类 [-0.8, 1.0]（放宽，因饱和反例只在进入饱和区才暴露）

## 十三、复现

```bash
python a_data/gen_mred_formal.py --dry     # 全量验算，不落盘
python a_data/gen_mred_formal.py           # 验算通过后落盘到 cases/
```

固定种子：划分 `20261007`，干预点 `20261007`，节点打乱/干扰源构造由 `stable_hash(group_id, ...)` 派生，可完全复现。已推送版本的所有随机决策均由稳定哈希确定，不依赖运行时状态。
